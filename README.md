# 画像容量調整ツール

JPEG・PNG・HEIC / HEIF画像を、用途に応じた設定でJPEGへ変換するWindows向けデスクトップアプリです。

複数画像の一括処理、ドラッグ＆ドロップ、容量比較、印刷向け設定、処理ログの確認・CSV出力に対応しています。

## 主な機能

- JPEG / PNG / HEIC / HEIF画像の読み込み
- 複数画像の一括処理
- ドラッグ＆ドロップで画像追加
- 3段階の通常圧縮
- 目標容量を指定する数値指定
- L判 / はがき / A4 / A3向けの印刷設定
- ppiによる印刷適性判定
- 圧縮前後の容量比較
- 成功 / 警告 / 失敗の色分け表示
- 実行単位で確認できる処理ログ
- CSV形式でのログ出力
- 元画像を上書きせずJPEGとして保存

## 圧縮設定

### 通常設定

簡単に使える3段階のプリセットです。起動時は「最低画質（容量優先）」が選択されています。

| モード | JPEG品質 |
| --- | ---: |
| 最低画質（容量優先） | 60 |
| 標準 | 80 |
| 高画質 | 90 |

通常設定では目標容量を指定せず、選択したJPEG品質で保存します。

### 詳細設定：数値指定

指定した目標容量以下になる範囲で、可能な限り高いJPEG品質を二分探索します。

画像の内容によっては、最低画質まで下げても目標容量以下にならない場合があります。

### 詳細設定：印刷設定

印刷サイズと印刷品質を指定し、固定JPEG品質で保存します。

対応する印刷サイズ：

- L判：89 × 127 mm
- はがき：100 × 148 mm
- A4：210 × 297 mm
- A3：297 × 420 mm

| 印刷品質 | JPEG品質 | 判定基準 |
| --- | ---: | ---: |
| 最低画質（容量優先） | 75 | 150 ppi以上 |
| 標準 | 88 | 240 ppi以上 |
| 高画質 | 95 | 300 ppi以上 |

画像の縦横方向を用紙に合わせて実効ppiを計算し、「印刷判定」に適合 / 不足を表示します。

ppi値はアプリ内の実用的な目安です。実際の見え方はプリンター、用紙、閲覧距離、画像内容などによって変わります。

## 設定の選択

- 「通常設定」と「詳細設定」はどちらか一方を使用します。
- 詳細設定では「数値指定」と「印刷設定」のどちらか一方を使用します。
- 選択していない詳細設定欄は非表示になります。

## 処理ログ

画面右側に処理結果を表示します。

主な表示項目：

- ファイル名
- 元容量
- 変換後容量
- 容量変化率
- 結果
- JPEG品質
- 画像サイズ
- 印刷設定
- ppi
- メッセージ

最新の「圧縮を開始」の実行結果が上に表示され、実行ごとに区切りが入ります。

容量が減った場合は容量変化率がマイナス、増えた場合はプラスで表示されます。JPEG変換後の容量が元画像より増えた場合も、変換目的を考慮して保存を継続し、警告として表示します。

ログはCSVとして保存できます。

## 対応形式

**入力**

- JPEG
- PNG
- HEIC
- HEIF

**出力**

- JPEG

## ソースコードから実行する場合

Python環境を用意し、プロジェクトフォルダで以下を実行します。

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## Windows版

Windows向け実行ファイルはGitHub Releasesから配布する予定です。

ソースコードからexeを作成する場合：

```powershell
pip install pyinstaller
pyinstaller --noconfirm --windowed --name ImageCompressor main.py
```

生成後は `dist\ImageCompressor\ImageCompressor.exe` で動作確認してください。

## 注意事項

- 元画像は上書きしません。
- PNG / HEIC / HEIFからJPEGへ変換した場合、画像内容や設定によって元画像よりファイル容量が増えることがあります。
- 目標容量指定は、必ず指定容量以下になることを保証するものではありません。
- 印刷適性のppi判定は目安です。
