# 画像容量調整ツール Ver.1.3.8

JPEG・PNG・HEIC画像を、用途に応じた設定でJPEGへ変換するWindows向けデスクトップアプリです。

## Ver.1.3.8 の設定方式

### 通常設定
通常利用向けの簡単なプリセットです。

- 標準: JPEG品質 80
- 高画質: JPEG品質 90
- 最低画質（容量優先）: JPEG品質 60

通常設定は目標KBを指定せず、選択したJPEG品質で保存します。

### 詳細設定 > 数値指定
Ver.1.0と同じ方式です。指定した目標容量以下になる範囲で、可能な限り高いJPEG品質を二分探索します。

### 詳細設定 > 印刷設定
印刷サイズと印刷品質を指定します。容量目標は使わず、印刷品質に対応する固定JPEG品質で保存します。

印刷サイズ:
- L判: 89 x 127 mm
- はがき: 100 x 148 mm
- A4: 210 x 297 mm
- A3: 297 x 420 mm

印刷品質とアプリ内判定基準:
- 最低画質（容量優先）: JPEG品質75 / 150 ppi以上
- 標準: JPEG品質88 / 240 ppi以上
- 高画質: JPEG品質95 / 300 ppi以上

画像の縦横方向を用紙に合わせたうえで実効ppiを計算し、一覧の「印刷判定」に適合/不足を表示します。
このppi値はアプリ内の実用的な目安であり、プリンター、用紙、閲覧距離、画像内容によって実際の見え方は変わります。

## 排他選択

- 「通常設定」と「詳細設定」はどちらか一方だけ有効です。
- 詳細設定内の「数値指定」と「印刷設定」もどちらか一方だけ有効です。
- 選択されていない設定欄はグレーアウトします。

## 対応形式

入力: JPEG / PNG / HEIC / HEIF
出力: JPEG

## 実行

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## exe化

```powershell
pip install pyinstaller
pyinstaller --noconfirm --windowed --name ImageCompressor main.py
```

まず `dist\ImageCompressor\ImageCompressor.exe` で動作確認してください。


## Ver.1.3.8 修正内容

- 詳細設定を選択していない場合、詳細設定領域を完全に非表示に変更
- 数値指定と印刷設定も、選択していない側を非表示に変更
- 画像一覧の表示領域を拡大
- JPEG変換後に元画像より容量が増えた場合も保存を継続
- 容量増加時は「警告」として表示
- 結果行を色分け
  - 成功: 緑
  - 警告: 黄
  - 失敗: 赤
- 容量が増加した場合、削減率はマイナス値で表示


## Ver.1.3.8 追加・変更内容

- 画面を左右分割し、右側に処理ログを追加
- 左右の境界はドラッグして表示幅を変更可能
- 右側が狭い場合は「時刻・ファイル名・結果」を中心に確認
- 右側を広げると以下の詳細を比較可能
  - 入力形式 / 出力形式
  - 圧縮設定
  - JPEG品質
  - 元容量 / 変換後容量
  - 容量変化率
  - 画像サイズ
  - 印刷設定
  - ppi
  - メッセージ
- 同じ画像を何度処理してもログを消さず、設定ごとの結果を縦に比較可能
- 画像一覧の「削減率」を「容量変化率」に変更
  - 容量削減：マイナス
  - 容量増加：プラス
- 処理ログも成功=緑、警告=黄、失敗=赤で色分け
- UIログとCSV出力は同じ LogEntry データを使用
- CSVはExcelで開きやすい UTF-8 BOM付きで保存
- 「すべて削除」は画像一覧のみを消し、比較用ログは残す

### CSV出力項目

日時、ファイル名、結果、入力形式、出力形式、設定、JPEG品質、
元容量、変換後容量、容量変化率、画像サイズ、印刷設定、ppi、
メッセージ、入力パス、出力パス
